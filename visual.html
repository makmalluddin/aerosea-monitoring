Aerosea Monitoring

Aplikasi pemantauan ruang laut dan udara interaktif. Sistem ini merender data telemetri menggunakan arsitektur antarmuka React yang dipadukan dengan aliran data seketika (*live streams*) dan arsip data lampau, menghadirkan visualisasi pergerakan objek secara presisi di atas kanvas peta tunggal.

Nusantara

Arsip Data Kapal

HISTORIS

Data pergerakan maritim lampau ini dihimpun dari hasil tangkapan AIS Receiver lokal berbasis Raspberry Pi (menggunakan decoder Python) dan digabungkan dengan arsip penugasan selama program magang (IT Assistant).

Format: JSON/CSV Status: Termuat

Arsip Data Pesawat

HISTORIS

Data lintasan penerbangan udara lampau ditarik dari titik akhir REST API OpenSky Network. Rekaman rute pesawat ini disimpan dan disusun dalam basis data untuk disimulasikan ulang melalui fitur pemutaran layar (*playback*).

Database: MongoDB Status: Termuat

Aliran Telemetri Live

SEKETIKA

Koneksi dua arah berkelanjutan menggunakan Socket.io. Mengambil arus posisi kapal laut langsung dari WebSocket AISStream.io dan posisi seketika lintasan udara dari OpenSky Live.

Backend Node.js/Express: Terhubung
Ping Soket: 14 ms
